# Facturia — Facturación simple para PYMES

Facturia es una aplicación web para crear, enviar y controlar facturas
electrónicas pensada para pequeños negocios y freelancers de América Latina.
El objetivo es que emitir una factura tome menos de un minuto y que al final del
mes sepas exactamente cuánto facturaste, cuánto cobraste y cuánto te deben.

## Para quién es

- Freelancers y profesionales independientes que facturan a varios clientes.
- Pequeños comercios y talleres que necesitan facturas y recibos ordenados.
- Startups en etapa temprana que aún no justifican un sistema contable completo.

## Qué resuelve

- **Facturas en segundos**: plantillas listas, numeración automática y cálculo
  de impuestos (ITBMS, IVA) según el país configurado.
- **Cobros claros**: cada factura tiene un estado (borrador, enviada, pagada,
  vencida) para que sepas de un vistazo quién te debe.
- **Recordatorios automáticos**: Facturia envía un correo amable al cliente
  cuando una factura está por vencer o ya venció.
- **Reportes**: ingresos por mes, por cliente y por categoría, exportables a
  PDF y CSV.

## Cómo empezar

1. Crea una cuenta gratuita en la web de Facturia.
2. Completa los datos de tu negocio (nombre, identificación fiscal, logo).
3. Agrega tu primer cliente y emite tu primera factura.

No se necesita tarjeta de crédito para usar el plan gratuito.
